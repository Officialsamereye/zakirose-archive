# Zaki Rose Archive

Moves finished projects off LucidLink into Dropbox (or Google Drive) in the background, verifies every file, and only removes the LucidLink copy after you confirm.

## Install or update (Mac)

Paste into Terminal:

```
curl -fsSL https://raw.githubusercontent.com/Officialsamereye/zakirose-archive/main/install.sh | bash
```

Run the same line again any time to update. Settings and reports are kept.
